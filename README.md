# MANASIK

Unified Hajj & Umrah marketplace for Ethiopia, developed by Hisab Technologies PLC.

## Phase 1

Next.js + TypeScript + Supabase. Dedicated backend project: `kgewofhjunfypqsylsjq`.

Security: never commit Supabase secret/service-role keys. Agency authorization and bookings must be enforced server-side.

## Setup

1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env.local` and configure public Supabase URL and publishable key.
3. Run `npm run dev`.

This repository is under active development and is not production-ready.
